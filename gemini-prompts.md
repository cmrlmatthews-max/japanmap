## How to use this sheet

1. Open Gemini and start a new chat for each asset. A fresh chat avoids style drift from earlier images.
2. Copy the prompt from the code block. Paste it. Send it.
3. Gemini often returns several options. Pick the one with the most negative space and the cleanest edges.
4. Download the PNG.
5. Rename the file to the exact filename shown in the asset heading.
6. Save it in the `assets/` folder of the project.

### Naming rules

- Use kebab-case. Use lowercase letters, numbers, and hyphens only.
- Use the exact filename in each heading. The app loads files by those names.
- Keep the `.png` extension.

### Export settings

- Format: PNG.
- Size: match the size listed for each asset.
- Gemini may not return the exact pixel size. If the size is off, open the file in Preview on Mac. Choose Tools > Adjust Size. Turn off "Scale proportionally" only if the aspect ratio is already correct. Otherwise regenerate and ask for the right aspect ratio.
- Wide strips (for example 2048x256) may come back with a less extreme ratio. Crop them in Preview with Tools > Rectangular Selection, then Tools > Crop.

### Palette (used in every prompt)

| Name | Hex | Use |
|---|---|---|
| Rice-paper cream | #F5EFE0 | Paper, light areas |
| Sumi ink black | #2C2C2A | Lines, calligraphy, dark ink |
| Three greys | light, mid, dark | Mountain and mist layers |
| Vermilion red | #C8341E | The only accent color |
| Gold | #C9A227 | Fall assets only. Use sparingly. |

### Transparent backgrounds: read this first

Gemini may ignore "transparent background". It often draws a white or checkerboard background instead. Use one of these two fixes.

**Fix A: magenta key.**
1. Add this sentence to the end of the prompt: `Place the artwork on a solid flat magenta background, color #FF00FF, with no shadows and no texture on the background.`
2. Download the PNG.
3. Tell the developer (Claude) the file is on magenta. The app removes magenta #FF00FF in code.
4. Do not use magenta anywhere in the artwork itself. The palette has no magenta, so this is safe.

**Fix B: Preview on Mac.**
1. Open the PNG in Preview.
2. Click the Markup toolbar button, then click Instant Alpha (the magic wand icon).
3. Click and drag on the background. The background turns red. Release.
4. Press Delete.
5. Repeat for any leftover patches.
6. Save with File > Export, format PNG.

Fix B works best on flat, plain backgrounds. Use Fix A for sprite sheets and fine brush edges.

## 1. Washi paper tile

- **Filename:** `washi-paper-tile.png`
- **Size:** 1024 x 1024 px
- **Transparent:** No
- **Purpose in app:** Repeating background for panels and the map table. It must tile without visible seams.

```text
Create a seamless tileable texture of Japanese washi rice paper, square format, 1024 by 1024 pixels. Base color is warm rice-paper cream #F5EFE0. Add very subtle long paper fibers in slightly darker cream and a few faint pale-grey flecks. Keep all detail low contrast so text can sit on top. The texture must tile: the left edge must match the right edge, and the top edge must match the bottom edge. No border. No vignette. No folds. No stains. No ruled lines. No text. Flat 2D look, no 3D render, no photorealistic lighting, no gradient from center to edge. Japanese sumi-e and ukiyo-e paper feel. Original artwork.
```

**If it comes out wrong:**
- Visible seams or a dark edge: add `Every edge is the same plain texture as the center. No vignette, no shading toward the edges.` and regenerate. As a backup, ask the developer to blend the edges in code.
- Too busy or too dark: add `Make the fibers 50 percent fainter and keep the whole image within 5 percent of the base cream color.`

### Process notes

- From prompt 2 on, the prompts ask for a plain white ground instead of magenta. Gemini then paints no sheet and no border.
- `tools/ink-alpha.py IN OUT --trim` turns a painting into ink on transparent: alpha = darkness against the ground. Magenta and the edge of a painted sheet are removed first. Vermilion marks keep their colour.
- `tools/key-magenta.py` is still right for assets with colour (crests, leaves). Use `ink-alpha.py` for grey ink paintings.
- The Gemini page needs a click in the prompt box after it loads. The Return key does not send; click the arrow at the right of the box.
- Downloaded images land in `/Users/cade/Claude-Sandbox/Personal Projects/` as `Gemini_Generated_Image_*.jpeg`. Move them at once with `mv` through osascript.
